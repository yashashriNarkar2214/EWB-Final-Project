# EWB Student Management Backend API

## Overview
A production-ready RESTful API built with **FastAPI**, **SQLAlchemy**, **Pydantic**, and **SQLite**[cite: 59] featuring complete CRUD operations and an optional local AI query extension powered by **Ollama (Llama 3.2)**[cite: 2, 59].

## Prerequisites
- Python 3.10+
- Ollama (optional, for local AI extension)[cite: 2, 59]
